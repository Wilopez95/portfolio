# Action verbs (ES / EN)

Start every bullet with one of these. Use past tense for past roles and present for the current
role. Do not repeat a verb within the same role. Pick the verb that matches the real scope: do not
write "Lideré" or "Led" if the candidate did not lead.

| Area | Español | English |
|---|---|---|
| Customer service / sales | Atendí, Asesoré, Resolví, Fidelicé, Vendí, Superé (meta), Recomendé, Gestioné (reclamos) | Served, Advised, Resolved, Retained, Sold, Exceeded, Upsold, Handled |
| Cash / admin | Cuadré, Concilié, Registré, Facturé, Archivé, Digitalicé, Procesé, Verifiqué | Balanced, Reconciled, Recorded, Invoiced, Filed, Digitized, Processed, Verified |
| Operations / logistics | Despaché, Recibí, Almacené, Inventarié, Cargué, Distribuí, Organicé, Clasifiqué | Shipped, Received, Stored, Inventoried, Loaded, Distributed, Organized, Sorted |
| Improvement | Reduje, Optimicé, Agilicé, Mejoré, Estandaricé, Automaticé, Simplifiqué | Reduced, Optimized, Streamlined, Improved, Standardized, Automated, Simplified |
| Leadership / people | Lideré, Coordiné, Supervisé, Capacité, Entrené, Asigné, Evalué, Integré | Led, Coordinated, Supervised, Trained, Coached, Assigned, Evaluated, Onboarded |
| Creation / projects | Implementé, Diseñé, Desarrollé, Lancé, Creé, Organicé (evento), Planifiqué | Implemented, Designed, Developed, Launched, Created, Organized, Planned |
| Analysis / control | Analicé, Monitoreé, Controlé, Audité, Reporté, Detecté, Pronostiqué | Analyzed, Monitored, Controlled, Audited, Reported, Identified, Forecasted |
| Communication | Presenté, Negocié, Redacté, Comuniqué, Traduje, Medié | Presented, Negotiated, Wrote, Communicated, Translated, Mediated |
| Care / health / hospitality | Asistí, Cuidé, Preparé, Atendí, Higienicé, Acompañé | Assisted, Cared for, Prepared, Attended, Sanitized, Supported |
| Technical / maintenance | Reparé, Instalé, Operé, Mantuve, Diagnostiqué, Calibré | Repaired, Installed, Operated, Maintained, Diagnosed, Calibrated |

Avoid weak openers: "Encargado/a de", "Responsable de", "Funciones:", "Ayudé en",
"Responsible for", "Duties included", "Helped with". Rewrite them with a verb from the table.

Present tense for the current role (ES): Atiendo, Coordino, Gestiono… EN: Serve, Coordinate, Manage…
